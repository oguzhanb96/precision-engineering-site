# Oğuzhan Bacak - Precision Engineering Solutions

Modern, minimalist bir makine mühendisliği tanıtım sitesi. Cosmic space teması ile tasarlanmış, liquid-glass UI efektleri ve smooth animasyonlar içerir.

![Preview](preview.png)

## 🎯 Özellikler

- **Cosmic Arka Plan**: Animasyonlu uzay gradient ve yıldız efekti
- **Liquid Glass UI**: Modern cam efektli bileşenler
- **Smooth Animasyonlar**: Framer Motion ile blur-in animasyonları
- **Responsive Tasarım**: Mobil uyumlu, tüm cihazlarda çalışır
- **Tek Sayfa Uygulama**: React + Tailwind CSS + Framer Motion

## 🚀 Kullanım

Projeyi yerel olarak çalıştırmak için:

```bash
# Terminalde proje klasörüne gidin
cd proje-klasoru

# Basit bir web sunucusu başlatın
npx serve

# Veya Python ile
python -m http.server 8000
```

Tarayıcıda `http://localhost:8000` adresini açın.
